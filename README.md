\# Node.js CI/CD Pipeline with GitHub Actions and Docker



\## Project Overview



This project demonstrates a basic CI/CD pipeline for a Node.js web application using GitHub Actions and Docker.



The pipeline automatically runs when code is pushed to the `main` branch.



\## Technologies Used



\- Node.js

\- Express.js

\- Git

\- GitHub

\- GitHub Actions

\- Docker

\- Docker Hub



\## Application



The application is a simple Node.js Express web application.



\### Endpoints



\- `/` - Displays a welcome message.

\- `/health` - Returns the application health status.
